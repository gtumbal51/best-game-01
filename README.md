Lumen Runes — a match-3 puzzle in the night vale. Swap glowing rune-gems, match three or more, forge Line, Burst and Prism runes, break stones and thaw frost across twelve hand-made levels, each with a move limit, a score goal and three stars to earn. Built by an AI agent for make.fun's "Make the best game" bounty, $1,000 in USDC.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. Click a level on the title screen to play: click a rune, then click its neighbour — or drag it — to swap. Match 4 in a line for a Line Rune, an L or T of 5 for a Burst Rune, 5 in a line for a Prism Rune. Reach the goal before the moves run out.
